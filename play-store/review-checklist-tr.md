# Sonsuz Ucus - Play Store Yayin Kontrol Listesi

## 1. Kod ve Paket

- [ ] Uygulama adi: Sonsuz Ucus
- [ ] Paket adi: `com.senisim.sonsuzucus`
- [ ] Surum: `1.0`
- [ ] Version code: `1`
- [ ] Minimum Android: API 24
- [ ] Target SDK: API 36
- [ ] Release AAB uretildi.
- [ ] Release AAB gercek yayin anahtari veya Play App Signing akisi ile imzali.

## 2. Reklam

- [ ] Play Console'da "Contains ads" = Yes.
- [ ] Manifest icindeki test AdMob App ID gercek App ID ile degisti.
- [ ] `AdMobService.cs` icindeki banner, interstitial ve rewarded test unit ID'leri gercek unit ID'ler ile degisti.
- [ ] Reklamlar oyun icinde kontrolu bozmayacak sekilde sonuc/menu akisini izliyor.
- [ ] Odullu reklam sadece kullanici butona bastiginda aciliyor.

## 3. Gizlilik ve App Content

- [ ] `docs/public/privacy.html` GitHub Pages veya baska bir herkese acik HTTPS adreste yayinlandi.
- [ ] Play Console Store Listing gizlilik politikasi URL'si girildi.
- [ ] App Content > Privacy Policy tamamlandi.
- [ ] App Content > Ads tamamlandi.
- [ ] App Content > Data Safety tamamlandi.
- [ ] App Content > Target audience and content tamamlandi.
- [ ] App Content > Content rating/IARC tamamlandi.
- [ ] Hassas izin yok: kamera, mikrofon, rehber, hassas konum, SMS, cagri kaydi yok.

## 4. Magaza Listeleme

- [ ] Kisa aciklama girildi.
- [ ] Uzun aciklama girildi.
- [ ] Kategori secildi: Game / Arcade.
- [ ] Uygulama ikonu yuklendi: `play-store/graphics/icon-512.png`
- [ ] En az iki telefon ekran goruntusu yuklendi: `play-store/graphics/phone-screenshots/`

- [ ] Iletisim e-posta adresi girildi.

- [ ] Dikey modda 10 oyun oynandi.

- [ ] Ses kapatma/acma, muzik kapatma/acma ve motor sesi ayarlari test edildi.
- [ ] Dusuk yakit uyarisi test edildi.
- [ ] Duvar/zemin carpma geri bildirimi test edildi.
